Messagerie

Nécessaire pour recevoir les alertes. Sans ces réglages, l'application fonctionne normalement mais reste muette.

Gmail : smtp.gmail.com · Orange : smtp.orange.fr
587 dans la plupart des cas

Avec Gmail, il faut un mot de passe d'application, créé dans les réglages de sécurité du compte Google. Le mot de passe habituel est systématiquement refusé. Ce mot de passe est conservé en clair dans la base de données, sur votre NAS — le chiffrer avec une clé rangée à côté ne protégerait de rien.
